# Sleek A statically-typed, sleek, ergonomic, expressive, and modern programming language designed for clarity and performance. > Currently in early development (work in progress), so expect breaking changes and incomplete features. The design is still evolving, and feedback is welcome! ## Extension All sleek files have the `.sl` extension. ## Syntax Sleek's syntax is designed to be *sleek*, clean and intuitive, drawing inspiration from popular and industry-standard languages.
### Comments
C-styled comments, with single-line comments using `//` and multi-line comments enclosed in `/* */`. ```sleek // This is a single-line comment /* This is a multi-line comment */ ```
### Variables
Variables in Sleek are declared using `let` or `const`. ```sleek let x = 5; // mutable integer x = 10; // allowed const y = 10.5; // immutable float y = 20.5; // error: cannot reassign to constant variable ``` But wait, Sleek was supposed to be statically-typed! The above example is actually an example of type inference, where the compiler automatically matches the type based on the assigned value. Isn't that *sleek*? However, if you want to explicitly specify the type, be my guest! ```sleek let int x = 5; // mutable integer const float y = 10.5; // immutable float ```
### Functions
Functions in Sleek are declared using the `fn` keyword. ```sleek fn add(int a, int b) { return a + b; } fn main() { let result = add(5, 10); println(result); // Output: 15 } ``` And I don't know if you noticed, but the `add` function has an implicit return type of `int`, and the `main` function returns `null`, which is inferred from the return statement (which ironically doesn't exist). Sleek's type inference is pretty powerful, isn't it? But of course, you can also explicitly specify the return type if you want. ```sleek fn int add(int a, int b) { return a + b; } fn void main() { let result = add(5, 10); println(result); // Output: 15 } ```
### Control Flow
Sleek supports standard control flow constructs like `if`, `else`, `while`, and `for`. ```sleek fn main() { let x = 10; if (x > 5) { println("x is greater than 5"); } else { println("x is less than or equal to 5"); } let i = 0; while (i < 5) { println(i); i = i + 1; } for (let j = 0; j < 5; j++) { println(j); } } ```
### Arrays
Arrays in Sleek are declared using square brackets `[]`. ### Fixed arrays : ```sleek fn main() { let arr = [1, 2, 3, 4, 5]; // int[5] = int[capacity], with 5 elements initialized println(arr); // Output: [1, 2, 3, 4, 5] // would be error: cannot push beyond the fixed capacity // arr.push(6); arr.remove(2); // removes the element at index 2 (value 3) arr.push(6); // now possible since there is capacity println(arr); // Output: [1, 2, 4, 5, 6] println(arr.length == arr.capacity); // Output: true // explicit size let arr2[10] = [1, 2] // int[10] with 2 elements initialized println(arr2); // Output: [1, 2] println(arr2[5]); // Output: null println(arr2.length < arr2.capacity); // Output: true } ``` ### Dynamic arrays : ```sleek fn main() { let arr[] = [1, 2, 3]; // int[] with 3 elements println(arr); // Output: [1, 2, 3] println(arr.length, arr.capacity); // Output: 3, -1 (capacity is -1 for dynamic arrays) arr.push(4); // dynamically resizes the array to accommodate the new element println(arr); // Output: [1, 2, 3, 4] arr.remove(1); // removes the element at index 1 (value 2) println(arr); // Output: [1, 3, 4] } ``` ### Const arrays : ```sleek fn main() { const arr3 = [1, 2, 3]; // const int[3] println(arr3); // Output: [1, 2, 3] arr3[0] = 10; // error: cannot modify a constant array arr3.remove(1); // error: cannot modify a constant array arr3.push(4); // error: cannot modify a constant array const arr[] = [1, 2, 3]; // error: constant arrays cannot be dynamic } ``` ### References to arrays : ```sleek fn main() { let arr0 = [1, 2, 3]; // int[3] with 3 elements let arr1[] = [1, 2, 3]; // int[] with 3 elements let &ref0 = arr0; // &int[3] let &ref1 = arr1; // &int[] ref0[0] = 10; // modifies arr0 since ref0 is just a reference println(arr0); // Output: [10, 2, 3] println(ref0); // Output: [10, 2, 3] ref1.push(10); // modifies arr1 since ref1 is just a reference println(arr1); // Output: [1, 2, 3, 10] println(ref1); // Output: [1, 2, 3, 10] } ``` ### Const references to arrays : ```sleek fn main() { let arr0 = [1, 2, 3]; // int[3] with 3 elements let arr1[] = [4, 5, 6]; // int[] with 3 elements const &ref0 = arr0; // const &int[3] println(ref0); // Output: [1, 2, 3] arr0[0] = 10; println(ref0); // Output: [10, 2, 3] (reflects changes to arr0) const &ref1 = arr1; // const &int[] println(ref1); // Output: [4, 5, 6] arr1.push(10); println(ref1); // Output: [4, 5, 6, 10] (reflects changes to arr1) ref0[0] = 20; // error: cannot modify through a const reference ref1.push(20); // error: cannot modify through a const reference // Const reference to const array delegates to a const reference const arr2 = [7, 8, 9]; // const int[3] const ref2 = arr2; // const int[3] const &ref2 = arr2; // const &int[3] } ``` ### Copying arrays : Since references are handled explicitly in Sleek, copying an array is just as simple as assigning it. ```sleek let arr0 = [1, 2, 3]; // int[3] with 3 elements let arr1 = arr0; // Creates an independent copy of arr0 arr1[0] = 10; // Modifying arr1 does not affect arr println(arr0); // Output: [1, 2, 3] println(arr1); // Output: [10, 2, 3] ```
### Null safety
Sleek has built-in null safety features to prevent null reference errors. By default, all types are non-nullable, meaning they cannot hold a null value. If you want a variable to be able to hold null, you can use the `?` syntax to make it nullable. ```sleek let int nullableInt?; // nullable integer println(nullableInt); // Output: null nullableInt = 10; // now holds a non-null value println(nullableInt); // Output: 10 let nullable? = 10; // (same as above, via inference) println(nullable); // Output: 10 nullable = null; // now holds a null value println(nullable); // Output: null // Non-nullable types cannot be assigned null let int nonNullableInt = null; // error: cannot assign null to a non-nullable type ``` ### Null safety with arrays : ```sleek int arr[] = [1, 2, 3]; // non-nullable array of non-nullable integers println(arr[0]); // Output: 1 arr = null; // error: cannot assign null to a non-nullable type arr[0] = null; // error: cannot assign null to a non-nullable type int nullable?[] = [1, 2, 3]; // nullable array of non-nullable integers println(nullable?[0]); // Output: 1 arr = null; // now arr can hold null println(nullable?[0]); // Output: null (delegates to null since the array itself is null) nullable?[0] = null; // error: cannot assign null to a non-nullable type int fullNullable??[] = [1, 2, 3]; // nullable array of nullable integers println(fullNullable?[0]); // Output: 1 fullNullable?[0] = null; // now the element at index 0 can hold null println(fullNullable); // Output: [null, 2, 3] fullNullable = null; // now the array itself can hold null println(fullNullable); // Output: null ```

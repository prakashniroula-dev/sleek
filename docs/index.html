# Sleek A statically-typed, sleek, ergonomic, expressive, and modern programming language designed for clarity and performance. > Currently in early development (work in progress), so expect breaking changes and incomplete features. The design is still evolving, and feedback is welcome!
Back to [Repo](https://github.com/prakashniroula-dev/sleek) ## Extension All sleek files have the `.sl` extension. ## Syntax Sleek's syntax is designed to be *sleek*, clean and intuitive, drawing inspiration from popular and industry-standard languages.
### Comments
C-styled comments, with single-line comments using `//` and multi-line comments enclosed in `/* */`. ```sleek // This is a single-line comment /* This is a multi-line comment */ ```
### Primitives ### Integer family : * `int16` : 16-bit signed integer (-32,768 to 32,767) * `int32` : 32-bit signed integer (-2,147,483,648 to 2,147,483,647) * `int64` : 64-bit signed integer (-9,223,372,036,854,775,808 to 9,223,372,036,854,775,807) * `int` : alias for `int32` ### Unsigned integer family : * `uint16` : 16-bit unsigned integer (0 to 65,535) * `uint32` : 32-bit unsigned integer (0 to 4,294,967,295) * `uint64` : 64-bit unsigned integer (0 to 18,446,744,073,709,551,615) * `uint` : alias for `uint32` ### Floating-point family : * `float32` : 32-bit floating-point number (single precision) * `float64` : 64-bit floating-point number (double precision) * `float` : alias for `float32` ### Other primitives : * `bool` : boolean type (true or false) * `string` : string type (UTF-8 encoded) * `char` : character type (UTF-8 encoded) * `byte` : byte type (8-bit unsigned integer) * `void` : represents the absence of a value (used for functions that do not return anything) * `null` : represents the absence of a value (can be assigned to nullable types)
### Variables
Variables in Sleek are declared using `let` or `const`. ```sleek let x = 5; // mutable integer x = 10; // allowed const y = 10.5; // immutable float y = 20.5; // error: cannot reassign to constant variable ``` But wait, Sleek was supposed to be statically-typed! The above example is actually an example of type inference, where the compiler automatically matches the type based on the assigned value. Isn't that *sleek*? However, if you want to explicitly specify the type, be my guest! ```sleek let int x = 5; // mutable integer const float64 y = 10.5; // immutable float let byte b = 255; // mutable byte ```
### Functions
Functions in Sleek are declared using the `fn` keyword. ```sleek fn add(int a, int b) { return a + b; } fn main() { let result = add(5, 10); println(result); // Output: 15 } ``` And I don't know if you noticed, but the `add` function has an implicit return type of `int`, and the `main` function returns `null`, which is inferred from the return statement (which ironically doesn't exist). Sleek's type inference is pretty powerful, isn't it? But of course, you can also explicitly specify the return type if you want. ```sleek fn int add(int a, int b) { return a + b; } fn void main() { let result = add(5, 10); println(result); // Output: 15 } ```
### Control Flow
Sleek supports standard control flow constructs like `if`, `else`, `while`, and `for`. ```sleek fn main() { let x = 10; if (x > 5) { println("x is greater than 5"); } else { println("x is less than or equal to 5"); } let i = 0; while (i < 5) { println(i); i = i + 1; } for (let j = 0; j < 5; j++) { println(j); } } ```
### Arrays
Arrays in Sleek are declared using square brackets `[]`. ### Fixed arrays : ```sleek fn main() { let arr = [1, 2, 3, 4, 5]; // int[5] = int[capacity], with 5 elements initialized println(arr); // Output: [1, 2, 3, 4, 5] // would be error: cannot push beyond the fixed capacity // arr.push(6); arr.remove(2); // removes the element at index 2 (value 3) arr.push(6); // now possible since there is capacity println(arr); // Output: [1, 2, 4, 5, 6] println(arr.length == arr.capacity); // Output: true // explicit size let arr2[10] = [1, 2] // int[10] with 2 elements initialized println(arr2); // Output: [1, 2] println(arr2[5]); // Output: null println(arr2.length < arr2.capacity); // Output: true } ``` ### Dynamic arrays : ```sleek fn main() { let arr[] = [1, 2, 3]; // int[] with 3 elements println(arr); // Output: [1, 2, 3] println(arr.length, arr.capacity); // Output: 3, -1 (capacity is -1 for dynamic arrays) arr.push(4); // dynamically resizes the array to accommodate the new element println(arr); // Output: [1, 2, 3, 4] arr.remove(1); // removes the element at index 1 (value 2) println(arr); // Output: [1, 3, 4] } ``` ### Const arrays : ```sleek fn main() { const arr3 = [1, 2, 3]; // const int[3] println(arr3); // Output: [1, 2, 3] arr3[0] = 10; // error: cannot modify a constant array arr3.remove(1); // error: cannot modify a constant array arr3.push(4); // error: cannot modify a constant array const arr[] = [1, 2, 3]; // error: constant arrays cannot be dynamic } ``` ### References to arrays : ```sleek fn main() { let arr0 = [1, 2, 3]; // int[3] with 3 elements let arr1[] = [1, 2, 3]; // int[] with 3 elements let &ref0 = arr0; // &int[3] let &ref1 = arr1; // &int[] ref0[0] = 10; // modifies arr0 since ref0 is just a reference println(arr0); // Output: [10, 2, 3] println(ref0); // Output: [10, 2, 3] ref1.push(10); // modifies arr1 since ref1 is just a reference println(arr1); // Output: [1, 2, 3, 10] println(ref1); // Output: [1, 2, 3, 10] } ``` ### Const references to arrays : ```sleek fn main() { let arr0 = [1, 2, 3]; // int[3] with 3 elements let arr1[] = [4, 5, 6]; // int[] with 3 elements const &ref0 = arr0; // const &int[3] println(ref0); // Output: [1, 2, 3] arr0[0] = 10; println(ref0); // Output: [10, 2, 3] (reflects changes to arr0) const &ref1 = arr1; // const &int[] println(ref1); // Output: [4, 5, 6] arr1.push(10); println(ref1); // Output: [4, 5, 6, 10] (reflects changes to arr1) ref0[0] = 20; // error: cannot modify through a const reference ref1.push(20); // error: cannot modify through a const reference // Const reference to const array delegates to a const reference const arr2 = [7, 8, 9]; // const int[3] const ref2 = arr2; // const int[3] const &ref2 = arr2; // const &int[3] } ``` ### Copying arrays : Since references are handled explicitly in Sleek, copying an array is just as simple as assigning it. ```sleek let arr0 = [1, 2, 3]; // int[3] with 3 elements let arr1 = arr0; // Creates an independent copy of arr0 arr1[0] = 10; // Modifying arr1 does not affect arr println(arr0); // Output: [1, 2, 3] println(arr1); // Output: [10, 2, 3] ``` Phew, that was quite a bit, who thought arrays could be so complex !
but if you try it out, you'll see how intuitively *sleek*, powerful and flexible it is.
### Null safety
Sleek has built-in null safety features to prevent null reference errors. By default, all types are non-nullable, meaning they cannot hold a null value. If you want a variable to be able to hold null, you can use the `?` syntax to make it nullable. ```sleek let int nullableInt?; // nullable integer println(nullableInt); // Output: null nullableInt = 10; // now holds a non-null value println(nullableInt); // Output: 10 let nullable? = 10; // (same as above, via inference) println(nullable); // Output: 10 nullable = null; // now holds a null value println(nullable); // Output: null // Non-nullable types cannot be assigned null let int nonNullableInt = null; // error: cannot assign null to a non-nullable type ``` ### Null safety with arrays : ```sleek int arr[] = [1, 2, 3]; // non-nullable array of non-nullable integers println(arr[0]); // Output: 1 arr = null; // error: cannot assign null to a non-nullable type arr[0] = null; // error: cannot assign null to a non-nullable type int nullable?[] = [1, 2, 3]; // nullable array of non-nullable integers println(nullable?[0]); // Output: 1 arr = null; // now arr can hold null println(nullable?[0]); // Output: null (delegates to null since the array itself is null) nullable?[0] = null; // error: cannot assign null to a non-nullable type int fullNullable??[] = [1, 2, 3]; // nullable array of nullable integers println(fullNullable?[0]); // Output: 1 fullNullable?[0] = null; // now the element at index 0 can hold null println(fullNullable); // Output: [null, 2, 3] fullNullable = null; // now the array itself can hold null println(fullNullable); // Output: null ```
### Unions, Struct & Enums
Unions, structs, and enums are powerful features in Sleek that allow you to define types that can hold multiple different values. Unions allow a variable to hold one of several types, structs allow you to define a custom data structure with named fields, while enums allow you to define a type that can be one of several named variants. ### Unions ```sleek union MyType[int, string]; // MyType can be either an int or a string fn main() { let MyType x = 10; let MyType y = "hello"; println("x is an int: {}", tag(x) == int); // Output: true println("y is a string: {}", tag(y) == string); // Output: true println("x: {}, y: {}", x, y); // Output: x: 10, y: hello // expression to handle different variants of the union match x { int i => println("x is an int: {}", i+1); string s => println("x is a string: {}", s + " world"); }; } ``` ### Structs ```sleek struct Point { int x; int y; fn move(Point &self, int dx, int dy) { self.x += dx; self.y += dy; } } fn main() { let Point p = { x: 10, y: 20 }; println("Point p: ({}, {})", p.x, p.y); let x = Point { x: 5, y: 5 }; println("Point x: ({}, {})", x.x, x.y); x.move(5, 5); println("Point x after moving: ({}, {})", x.x, x.y); } ``` ### Enums ```sleek // type can be omitted : inferred from the variants enum Color[int, string] { Red = 1, Green = 2, Blue = 3, Magenta = "magenta", Cyan = "cyan", // function bound to the enum itself (static method) fn Color::fromHex(string hex) { let color = match hex { "#ff0000" => Red; "#00ff00" => Green; "#0000ff" => Blue; "#ff00ff" => Magenta; "#00ffff" => Cyan; default => throw Error::ValueError("Invalid hex color"); }; return color; } // functions bound to the enum variants (instance methods) fn fromHex(Color &self, string hex) { let color = Color::fromHex(hex); self = color; } fn toHex(Color &self) { let hex = match self { Red => "#ff0000"; Green => "#00ff00"; Blue => "#0000ff"; Magenta => "#ff00ff"; Cyan => "#00ffff"; }; return hex; } } fn main() { let c = Color::fromHex("#ff0000"); println("Color c: {}", c); // Output: Color c: Red(1) println("Hex of c: {}", c.toHex()); // Output: Hex of c: #ff0000 c.fromHex("#00ff00"); println("Color c: {}", c); // Output: Color c: Green(2) c = Color::Magenta; println("Color c: {}", c); // Output: Color c: Magenta("magenta") match c { Color::Red => println("c is red"); Color::Green => println("c is green"); default => println("c is some other color: {}", default); }; } ```
